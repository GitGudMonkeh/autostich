# Soundtrack — download links

Generated by `npm run music:links` from `src/ui/music.js` and `media/music/`.
Re-run it after adding, renaming or re-tiering a track; the list is not updated automatically.

Links point at the repository copy on `main`. The same files are published to GitHub Pages
under `https://gitgudmonkeh.github.io/autostich/media/music/` by `.github/workflows/deploy-media.yml`.

Run durations per track and per tier: `npm run music:overview`.

## Download all at once

```bash
# sparse clone — music only, no app sources
git clone --depth 1 --filter=blob:none --sparse https://github.com/GitGudMonkeh/autostich.git
cd autostich && git sparse-checkout set media/music
```

```bash
# or pull the files straight out of this list
grep -o 'https://raw\.githubusercontent\.com/[^)]*\.m4a' docs/soundtrack-downloads.md \
  | sort -u | xargs -n1 -P4 curl -fLO --output-dir ./soundtrack
```
