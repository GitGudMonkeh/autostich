### The liveness probe was a threshold wearing an invariant's clothes

Its job is real: without it, a broken regular expression would satisfy every MENU-38 cap with
"0 found" and report green forever. But it was written as **`edgeIn(whole tree) > 30`** — a floor
under a number that **falls every time a worker does the right thing**. It was measured at 58 when it
was written, floored at 30, and M5's three conversions brought the tree to 29.

> **The guard went red because the vocabulary was applied correctly.** That is MR1's H-c word for
> word, and the answer is the same: rewrite to the invariant, never to a lower number. A lower number
> would have set the same trap for M6 and everyone after, until someone eventually weakened the
> ratchet to be rid of it.

**The invariant is not "the tree still contains N of them". It is: the expression recognises the
family.** That depends on no migration state, so it is no longer measured against one:

1. **A positive control** on a fixed string — it can never go stale and can never fall to a
   migration, only to someone breaking the expression, which is what it is for.
2. **A negative control** on a neighbouring value the expression must *not* take. An expression that
   grew too wide silences the ratchet exactly as reliably as one that grew too narrow, and the old
   probe could not see that at all. This is H-e's shape — *contains no X other than Y*, rather than
   *X is present*.
3. **An anchor in the tree that this round may not touch**: the three declarations on
   `.as-edge` / `.as-edge-strong` / `.as-edge-card` / `.as-edge-neutral`. `.as-edge-*` has 143 call
   sites, is not migrated this round, and its twelve alphas are an explicit non-goal in **every**
   contract of the round. Asserted with **`toBe(3)`**, not `toBeGreaterThan` — the number may neither
   fall nor grow, and reporting both directions is stricter than a floor that only looks down.

**Counter-checked, and the decisive case is the last one:**

| Defect reintroduced | Guard |
| --- | --- |
| the expression is broken (positive control) | **red** |
| the expression is widened to take a neighbour (negative control) | **red** |
| one `.as-edge-*` alpha is changed (the frozen anchor) | **red** |
| the anchor's end marker is renamed (locator liveness) | **red** |
| a new literal arrives in the `.gd-*` rules | **red** |
| a counted literal is silently swapped for a fresh one | **red** |
| the edge ratchet grows again in `.gd-*` | **red** |
| **a FURTHER successful migration takes the tree to 16** — far below the old floor of 30 | **GREEN**, as it must be. The old probe would have been red |
| the clean tree | **green** |
