# C6 — the cut is withdrawn, in every language

**Commit** `C6` · branch `task/mainscreen-brand` · base `2600c74f` · previous commit `ec478bac` ·
worktree `C:/Code/Autostich-worktrees/menu-rework` · ports preview 5189 · survey 5181.

**Owner decision Q12, 2026-08-26.** The cell column in the I is withdrawn. The wordmark carries its
ordinary glyph again, in every language. **The standalone 5 × 8 sign stays.**

**One sentence:** the wordmark is measurably the same object it was before this workstream touched it —
639 px in German and 634 in English, to the pixel, at both viewports — and what was removed was removed
rather than hidden.

## Part 2 — the zero-delta gates

### 2.1 Below 1280 px — zero

| | result |
| --- | --- |
| cells with any delta, C5 → C6 | **0 of 6** |

The narrow version never carried the column: C2 kept it out of the DOM with `useIsWide` and the
stylesheet held a second lock. Removing something the phone never had costs the phone nothing, and the
gate says so rather than the reasoning.

### 2.2 The wordmark is back to what it was before C2 — measured, not asserted

**This is the claim C6 has to support**, and the instrument for it is the C1 baseline, taken before a
single pixel of this workstream had landed:

| | pre-C2 (`evidence/C1`) | C6 | |
| --- | --- | --- | --- |
| `AUTOSTICH`, 1280 × 720 | 639 | **639** | identical |
| `AUTOSTICH`, 1920 × 1080 | 639 | **639** | identical |
| `AUTOTRICK`, 1280 × 720 | 634 | **634** | identical |
| `AUTOTRICK`, 1920 × 1080 | 634 | **634** | identical |

**Both languages, both viewports, to the pixel.** The wordmark is not *approximately* restored, it is
the same box. Anything else would have meant a leftover — a margin, a stray inline element, half a
rule.

### 2.3 Every surface but the hub — 220 deltas, all on one node, and it is the same node as C5's

**No structural change: 160 cells, 25 299 matched nodes, 0 unmatched.** The raw comparison against C5
finds deltas on exactly one node, and it is the mirror image of C5's:

| node | property | before → after |
| --- | --- | --- |
| `0/0/2/0/5/0/0:H1` — the wordmark | `box[w]` (110×) | **535.92 → 543.06** |
| the same | `box[x]` (110×) | half of that, because the column centres it |

C5 narrowed the wordmark by 1.19 CSS px and C6 gives back 7.14 — the difference between the scaled
column and the glyph it had replaced. **`543.06` is the value C1 measured before this workstream
began.** The five in-run surfaces are absent from the report entirely — **`run-stage` included.**

**Outside `.hub-root`: zero**, 160 cells, `evidence/C6/outside-the-hub.txt`.

### 2.4 The head zone did not move

| | C5 | C6 |
| --- | --- | --- |
| `.hub-play` height, 1280 × 720 | 561 | **561** |
| free height in the left column | 149 | **149** |
| page overflow, all eight viewports | 0 | **0** |

The wordmark's **line box** is governed by `line-height` and the h1's font size, not by what sits
inside it, so a taller or shorter inline child never changed the column's height. Only the width moved.

## Part 3 — what was removed, and the check that it is gone rather than dormant

| | removed |
| --- | --- |
| `StartScreen.jsx` | the split, `WORDMARK_I`, `logoHead` / `logoTail` / `logoI`, the `useIsWide` import and the `<BrandGrid cut="column" />` — the `<h1>` is `{t("start.logo.alt")}` again |
| `BrandGrid.jsx` | the `column` cut; `cellState` no longer takes one |
| `index.css` | `.hub-play .as-brandgrid-column`, its mid-tone rule (C5) and the comment block that argued the geometry |
| `marke.test.js` | eight assertions across five tests — the cut, the I position, the nine-character catalog claim, the flush geometry and the mid tone |

**Nothing is left dormant, and that is checked rather than intended** (C6-F02). The replacement guard
is written as an **absence**: `brandgrid-column` appears in none of the three files, `cut="column"` is
not rendered, and none of `WORDMARK_I`, `logoHead`, `logoTail`, `useIsWide` is left in the screen. A
guard that simply stopped asking could not notice the column growing back.

**The `--wm-size` relocation from C2 stays**, and its reason survives Q12 intact: the standalone mark
computes its height against `--wm-size`, and a value declared on the `<h1>` cannot be read by a
sibling. Only the half of the comment that argued about the column was removed.

**`cut="full"` stays as a named argument** although there is only one cut left. It costs nothing and it
says at the call site *what* is being rendered; a bare `<BrandGrid />` would be one word shorter and
one question longer.

## Part 4 — findings

| ID | Finding | Disposition |
| --- | --- | --- |
| **C6-F01** | **The wordmark is byte-identical to its pre-C2 measurement** — 639 / 634 px, both languages, both viewports | The strongest available evidence that the cut is gone rather than concealed. The C1 baseline turned out to be worth keeping for a reason nobody had in mind when it was taken |
| **C6-F02** | **What is removed is guarded as an absence.** Five tests were deleted and one was written in their place, asserting that neither the cut nor any of its four helper values is back | The alternative — deleting the tests and stopping there — leaves the invariant unwatched at exactly the moment it is most likely to be reintroduced |
| **C6-F03** | **The lockup probe had the old assertion for one run** and reported eight cells NOT REACHED: it still required exactly one sign *inside* the wordmark | Turned around rather than deleted: it now requires **zero** inside. The failure was the instrument correctly refusing to measure a screen it no longer understood, which is what "reachability is reported, never assumed" buys |
| **C6-F04** | **C5's two measurements outlive their subject.** Orbitron's cap height (`.71875em`, identical for every capital) and the arithmetic that made the gap-only route impossible are still true and now have no consumer | Left in `C5.md` with a line in the guard saying why the assertions above them were deleted. A measurement is not wrong because the thing it measured went away |
| **C6-F05** | **The design's core sentence is now struck through** — *"Zeichen und Name sind dieselbe Sache"* — together with four further sections that describe the same cut | Struck through **with their reasoning intact**, in the shape Q1a used, so the route is not proposed again in half a year. The decision's own reason is recorded beside it: the cut rested on a fact about two words, and a third language need not honour it |
